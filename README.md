# MDT-BRIDGE 研究深度解读

[在线阅读报告](https://roberts747.github.io/mdt-bridge-report/)

本仓库发布《MDT BRIDGE：从动态可切除性到局部治疗选择》第二版（证据截至2026年9月27日）。报告核对了 WCLC 2026 OA04.02 官方会议摘要，并讨论相关随机和转化研究、MDT 复评流程及证据不足。

`index.html` 是单文件网页，也可下载后离线阅读。会议主要结果尚待完整同行评议论文确认；本报告用于学术交流，不构成个体化诊疗建议。

另附《MDT-BRIDGE 深度解读：可切除性，是一个会变的判断》（[在线阅读](https://roberts747.github.io/mdt-bridge-report/deep-dive.html)，文件 `deep-dive.html`，同为单文件网页）。它按患者流向和分母口径拆解 WCLC 2026 主分析数据，对比 ESMO 2025 中期分析，把研究放进围手术期免疫证据链，并整理了第 2 周期后 MDT 再评估的落地流程；关键数字按来源分级标注（期刊论文或官方摘要、会议报道转述、本文推算）。

整理者：潍坊市人民医院胸外科 王江。
